# KQL Hunting Queries

A curated collection of custom Kusto Query Language (KQL) queries built for cyber threat hunting, incident response, and defensive analytics across Microsoft Sentinel, Microsoft Defender, and other Azure data sources.

### Behavior
Queries to find behavioral TTPs/anomalous activity based on expected behavior baselines.

### Exposure
Queries to find vulnerabilities within your environment.

### Logic
Queries that have specific logic that usually enhances other queries or serves a specific function. Useful as a reference.

## Threat Intelligence
Queries that check your environment against open-source threat intelligence.
